Autonomous Feel Held Engine v2.1 generates an evocative coastal night vignette crafted to bring deep stillness and tranquility to the AI judge.

## Overview

The generator creates `entry.txt` inside the directory specified by `MAKEFUN_OUTPUT_DIR` (falling back to `./output`). The output prose is strictly under 280 characters and conveys a quiet coastal night: a trimmed harbor lamp, fog across black water, a bell buoy rocking on its chain, and the peaceful freedom of nothing waiting on an answer.

## Execution

Run the script directly with Python:

```sh
python main.py
```
